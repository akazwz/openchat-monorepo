# 工具执行：agent loop 与执行器分离

状态（2026-10-01）：已实现 Worker 本地执行器、云电脑沙箱执行器和原生 Mac 执行器。Mac 的真实桌面与系统权限验证、发布状态见 [macOS 接入](macos.md)。

## 做法

agent loop 调用工具时不自己执行，交给一个执行器。loop 只认执行器接口，不知道工具在哪里、怎么执行。

- **工具声明 `ToolSpec`**：名称、说明、参数格式、是否只读（`readOnly`：中断后能否安全重跑；结果被滑动窗口清理后，只读的提示模型需要时重新调用，其余的提示已经执行生效、不要为了看输出而重复，见 [agent-design.md](agent-design.md) 第 3 节）、能否并行（`concurrent`：能否和同一步里相邻的调用同时执行）。两者分开声明：以前“只读”兼作“可并行”，带文件名保存的截图、等待页面出现文字都是只读的，却和后面的调用有先后关系，同一步里“截图存成文件”和“把这个文件发给用户”同时跑，发出的可能是旧图。只有只读的调用能并行。模型和 loop 只看到它。
- **执行器 `ToolExecutor`**：`execute(call, signal) → 结果`；可选的 `resume(call, signal)` 收集被打断的执行没跑完的调用的结果（还在跑的 shell 命令，见 [Agent 沙箱](sandbox.md)）——收不到就返回 `undefined`，由 loop 按“结果未知”处理；可选的 `close(runEnded)` 在每次执行结束时释放这次执行打开的连接（浏览器工具的 MCP 会话），Run 随之结束时再释放整个 Run 持有的东西（电脑的租约）；因暂时故障退避、等下一次执行继续的 Run 不释放租约。不抛错。driver 在确定这次执行的结局之后才调用它。
- **本地执行器**：由各模块的工具（声明 + 执行函数）组装，按工具名找到函数执行。搜索、网页、记忆、对话检索都在这里，和 loop 跑在同一个 Durable Object 里。
- **loop 保留的职责**：校验调用（工具是否存在、参数是否为 JSON 对象）；执行顺序规则（相邻的可并行调用同时执行，其余的调用等它们跑完、后面的调用等它跑完）；中断恢复规则——恢复一批未答的调用时，只有排在最前的那个可能已经开始：只读的直接重跑，会改变什么的靠执行器的 `resume` 收集结果，收不到就报告“结果未知”；其余调用（包括尝试在开始任何一个调用之前就结束的情形）都当新的执行。停止时如果没有执行在内存里（实例重启过），driver 用已经停止的信号去恢复那个排在最前、可能已经开始的调用，执行器照常停掉它（shell 命令被杀掉），不会显示已停止而命令还在电脑上跑。见 [运行时说明](agent-runtime.md)。执行失败统一变成模型能读的错误结果。

- **沙箱执行器**：`shell`、`read_file`、`write_file`、`edit_file` 等在用户自己的电脑（Cloudflare Sandbox）上执行；浏览器工具经电脑里的 Playwright MCP 执行，是另一个执行器，和沙箱执行器一起打包进电脑这一份 `ToolSet`（`sandboxToolSet`，按工具名把调用分给二者之一）。见 [Agent 沙箱](sandbox.md)。一个 Run 的工具再由 `composeToolSets` 组合，按工具名把调用分给声明它的 `ToolSet`。

- **原生 Mac 执行器**：`modules/devices/tools.ts` 的 `nativeRun` 为 Run 固定所选设备，保留相同 `ToolExecutor` 边界。命令、文件、截图和 computer use 由 `DeviceConnection` 经认证 WebSocket 派发给 Swift 执行端；网页、记忆、对话和邮件业务仍在 Worker。broker 与本机任务日志保留调用 ID 和结果，恢复时收集已执行结果，不重复产生副作用；关闭接入取消未完成任务。Run 结束释放它持有的 GUI 输入。人工远控的 WebRTC 会话独立于工具调用；Mac 文件不适用云电脑过期规则。

`modules/runs/driver.ts` 是运行调度（跑 loop、落库、处理取消），和执行器是两回事。

## 以后接其他执行器

原生 Mac 已通过此接口接入。其他 DO 或其他平台的本机执行器，同样实现 `ToolExecutor`，loop 不用改。后续按需要补充：

- 执行很久的调用：调用记录落库，执行期间 Run 挂起、结果回来再唤醒（复用 `RunActor.ensure`），避免 DO 一直挂着等。
- 失联和超时：超时时间、租约。
- 更多本机平台：复用设备登记、出站连接与执行器接口；按产品范围扩展能力和审批机制。
- 人工审批：调用先等用户同意再执行。
